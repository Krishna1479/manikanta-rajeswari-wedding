FREE HOSTING WITH GITHUB PAGES:
1. Sign in or create a free account at https://github.com
2. Create a new public repository, for example: teja-rajeswari-wedding
3. Upload all files and folders from this package (upload the contents, not just the ZIP).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”, select “main” and “/(root)”, then Save.
6. GitHub will provide a free address like https://YOUR-USERNAME.github.io/teja-rajeswari-wedding/

The site is static and has no paid hosting requirement. GitHub Pages does not automatically expire after the wedding; you can leave it online or take it down later.
